# PROMPT POUR CLAUDE OPUS — MONAFASSA IA v2 : CHATBOT + PANNEAU ADMIN (Replit)

## CONTEXTE ET MISSION

Tu es chargé de concevoir et développer une application web complète pour le **Chatbot IA Monafassa**, outil officiel du **Conseil de la Concurrence du Royaume du Maroc**.

L'application est hébergée sur **Replit** (Node.js + Express backend, HTML/CSS/JS frontend). Elle utilise l'**API OpenAI** (GPT-4o + Vector Store pour le RAG).

L'application doit comporter **deux parties distinctes** accessibles depuis la même URL :
1. **Interface Visiteur** — le chatbot juridique (déjà conçu, à conserver et améliorer)
2. **Panneau Administrateur** — gestion documentaire, feedbacks, analytics (à créer)

---

## STACK TECHNIQUE OBLIGATOIRE

- **Backend** : Node.js + Express (Replit)
- **Frontend** : HTML/CSS/JS servi par Express (fichier unique `public/index.html`)
- **IA** : OpenAI API — modèle `gpt-4o`
- **RAG** : OpenAI Responses API (`POST /v1/responses`) avec `file_search`
- **Vector Store ID** : `vs_69e0499e7fb081919b0157d8195caed6` (déjà configuré et indexé)
- **Clé API** : stockée dans les **Replit Secrets** sous la clé `OPENAI_API_KEY` (jamais dans le code)
- **Stockage admin** : fichier JSON local (`data/feedbacks.json` + `data/analytics.json`) ou SQLite via `better-sqlite3`
- **Auth admin** : JWT ou session simple avec mot de passe hashé (bcrypt) stocké dans Replit Secrets sous `ADMIN_PASSWORD_HASH`
- **Polices** : Instrument Serif + DM Sans (Google Fonts)
- **Design** : Flat, institutionnel, vert marocain (#2d6a4f), animations CSS subtiles

**POST /api/admin/documents/upload** — upload un nouveau PDF
```javascript
// 1. Recevoir base64 depuis frontend
// 2. Convertir en Buffer
// 3. POST /v1/files avec purpose='assistants'
// 4. POST /v1/vector_stores/{id}/files avec le file_id
// 5. Répondre avec statut

  file: new File([buffer], filename, { type: 'application/pdf' }),

  file_id: file.id
```

## FRONTEND — public/index.html

### Architecture JS

```javascript
// ── ÉTAT GLOBAL ──────────────────────────────────────────────────
const STATE = {
  mode: 'visitor',          // 'visitor' | 'admin'
  adminSection: 'docs',     // 'docs' | 'feedbacks' | 'analytics' | 'settings'
  adminToken: sessionStorage.getItem('adminToken') || null,
  // État visiteur existant...
  conversations: [],
  activeConvId: null,
  darkMode: localStorage.getItem('darkMode') === '1',
};

// ── ROUTER ───────────────────────────────────────────────────────
function render() {
  if (STATE.mode === 'admin' && STATE.adminToken) {
    renderAdmin();
  } else {
    renderVisitor();
  }
}

// ── API CLIENT ────────────────────────────────────────────────────
async function api(endpoint, options = {}) {
  const headers = { 'Content-Type': 'application/json' };
  if (STATE.adminToken) headers['Authorization'] = `Bearer ${STATE.adminToken}`;
  const res = await fetch(`/api${endpoint}`, { ...options, headers });
  if (res.status === 401) { logoutAdmin(); return; }
  return res.json();
}
```

## FLUX COMPLET — AJOUT D'UN DOCUMENT

```
Admin choisit PDF
    ↓
Frontend lit le fichier (FileReader)
    ↓
POST /api/admin/documents/upload { filename, base64, mimeType }
    ↓ (avec Bearer token)
adminAuth middleware vérifie JWT
    ↓
openai.files.create({ file: Buffer, purpose: 'assistants' })
    ↓ → file_id obtenu
openai.vectorStores.files.create(VECTOR_STORE_ID, { file_id })
    ↓ → statut 'processing' puis 'indexed'
Réponse { success, fileId, status: 'processing' }
    ↓
Frontend poll GET /api/admin/documents/:fileId/status toutes les 3s
    ↓ quand status === 'indexed'
Message : "✅ Document indexé — les visiteurs peuvent maintenant l'utiliser"
    ↓
IMMÉDIATEMENT : prochaine question visiteur → Vector Store inclut le nouveau doc
```

## CONTRAINTES ET BONNES PRATIQUES

1. **Sécurité** : `OPENAI_API_KEY` uniquement dans Replit Secrets, jamais dans le code ou le HTML
2. **Upload** : limiter à 20MB par fichier côté Express (`express.json({ limit: '25mb' })`)
3. **Concurrence** : utiliser des locks ou queues pour les écritures JSON simultanées
4. **Résilience** : si OpenAI API down, afficher message clair aux visiteurs
5. **Performance** : mettre en cache les réponses fréquentes (Map en mémoire, TTL 30min)
6. **Logs** : logger toutes les erreurs avec timestamp dans `data/errors.log`
7. **CORS** : désactiver en production (tout est sur le même domaine Replit)
8. **Validation** : valider tous les inputs admin (type fichier = PDF, taille, etc.)

## NOTE IMPORTANTE SUR LA CLÉ API

**Ne jamais mettre la clé API dans le code.** Sur Replit :
- Aller dans **Secrets** (icône cadenas dans le panneau gauche)
- Ajouter : `OPENAI_API_KEY` = votre clé
- Accès dans le code : `process.env.OPENAI_API_KEY`

La clé est automatiquement injectée comme variable d'environnement et n'est jamais exposée dans le code source ou le frontend.

## 1. CHAT (RAG)

POST /api/chat

- Input: message + history
- Uses OpenAI responses API with file_search
- Uses VECTOR_STORE_ID
- Returns:
  {
    success: true,
    answer: string,
    sources: [],
    annotations: []
  }

- Temperature = 0.1
- Max tokens = 3000

- MUST include:
  - error handling
  - fallback message if OpenAI fails
  - logging to analytics

## 2. ADMIN AUTH

POST /api/admin/login

- Compare password with bcrypt
- Return JWT (8h)

- Protect ALL /api/admin routes

## 3. DOCUMENT MANAGEMENT

- GET /api/admin/documents
- POST /api/admin/documents/upload (base64 PDF)

- Upload file to OpenAI

- Return status
